# AI Use Log — Template (preview only for Lab 00)

> **Not required for Lab 00.** Lab 00's AI policy is **AI-FREE** — there's no graded AI Use Log for the Hello Lab. This template ships with Lab 00 so you can see the format before Module 1, where the first AI-OPEN / AI-REQUIRED labs begin and the Use Log becomes a required submission artifact.

When a future lab requires an AI Use Log, the workflow is:

1. Copy this file to `AI_USE_LOG.md` in your local working copy (don't rename the template).
2. Fill in one row every time you interact with an LLM during the work — short summary in each cell.
3. Save the filled copy to your machine. `AI_USE_LOG.md` is `.gitignore`d so a `git add .` won't accidentally push your name to a public repo.
4. Upload the filled `AI_USE_LOG.md` as a **Canvas file attachment** — not to GitHub.

See [`docs/privacy-and-submission.md`](docs/privacy-and-submission.md) for the dual-track submission model that keeps identifying artifacts out of GitHub.
